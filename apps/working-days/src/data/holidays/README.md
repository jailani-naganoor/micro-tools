# Holiday data

Generated by `scripts/build-holiday-data.mjs` from the
[date-holidays](https://github.com/commenthol/date-holidays) package. Do not edit by hand —
upgrade `date-holidays` and run `npm run holidays -w @micro/working-days`.

The holiday data is available under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
(it relies on Wikipedia articles); these files are a subset of it and carry the same licence.
The site credits the source in "How it works" and on the About page.
